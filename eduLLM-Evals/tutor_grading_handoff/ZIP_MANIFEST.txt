ZIP MANIFEST — Slack/offline fallback for the Tutor Grading Handoff
===================================================================

Preferred delivery is GitHub (`main`): the teammate just checks out the repo and
opens tutor_grading_handoff/README.md. Use this list ONLY if sending a zip over
Slack instead. Zip these EXACT paths, preserving the repo-relative directory
layout (paths are relative to the repo root, eduLLM-Evals/).

----------------------------
tutor_grading_handoff/README.md
tutor_grading_handoff/OPERATIONS.md
tutor_grading_handoff/requirements.txt
tutor_grading_handoff/ZIP_MANIFEST.txt
tutor_grading_handoff/SLACK_MESSAGE.md

Bridge + ingestion scripts
--------------------------
scripts/run_judge_grading.py
scripts/validate_responses.py
scripts/stage_judge_inputs.py

-------------------
judge_frozen.yaml
config.yaml                         # default data paths / judge fallback block

------------------------------------------------------------------------------
tutor_cat/                          # whole package (dataio, judge, schemas, mirt, respgen, mcq_irt, ...)

Teammate judge runner + its deps
--------------------------------
aws_judge_handoff/                  # whole folder: scripts/run_judge_validation.py,

data/scenarios.jsonl                # scenario prompts + conversation context
